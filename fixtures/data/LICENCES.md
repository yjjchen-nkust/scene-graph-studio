# Slice licences

Two separate questions per dataset, because downloading for one's own use and distributing to a
class are different acts.

- **annotations_commit** — may derived annotations be committed to this repository?
- **bundle_distribute** — may the image files be distributed to enrolled students for classroom use?

`cut_slice.py` refuses to write `annotations.json` for a dataset whose `annotations_commit` is not
`YES`. `bundle_slices.py` refuses to include a dataset whose `bundle_distribute` is not `YES`.
`UNCLEAR` is treated as `NO`, and so is a blank.

Fill each row from the source's own licence statement, not a survey or a mirror, and record the URL
and the date read.

## Why each row reads as it does

**placeholder** — synthetic graphs and flat-colour PNGs generated by `backend/scripts/make_placeholders.py`
from nothing but code in this repository. No third party holds rights in them, so both gates are open.
This is the row that makes NFR-1 achievable: every lab must be demonstrable on a bare clone with no
corpora and no bundle.

**psg** — the OpenPSG repository states **MIT** and nothing else. Read 2026-09-16: it does *not*
distinguish the licence of its annotations from that of the underlying images, which are COCO
photographs. MIT covers what the repository itself contains; it does not reach photographs the
authors did not take and did not license. Annotations may therefore be committed, images may not be
redistributed. This is the row `test_the_two_licence_gates_disagree_where_the_evidence_says_they_should`
exists to protect — if both cells ever read the same, the distinction D-08 was created for is gone.

**vg150-sgb** — Visual Genome links CC BY 4.0. Read 2026-09-16: the link is presented without
accompanying text saying whether it covers the images as well as the annotations, and VG's images are
sourced from COCO and Flickr under their own terms. CC BY 4.0 plainly permits derived annotations with
attribution, so the first gate opens. The scope over images is unclear, and UNCLEAR counts as NO.

**vrd** — states no licence anywhere. An absent statement is not a permissive one. Both gates shut.

**indoorvg** — **corrected 2026-09-16, same day.** First read closed this row: the IndoorVG
GitHub repository states no licence, and SGG-Benchmark is MIT for its code only. That was an
incomplete search. The author also publishes the dataset on Hugging Face, and *that* card
states `license: cc-by-4.0` in its front matter. A dataset card is the source's own statement,
so the first gate opens. The lesson is recorded rather than quietly fixed: "the source's own
statement" means every place the source publishes, not the first one found.

**haystack** — states no licence anywhere. Both gates shut.

**mini-isg** — our own hand-corrected industrial set, but built on frames from third-party
corpora (IndustReal, MECCANO). D-18 puts the licence gate *before* any frame is committed, so
this row stays shut until each source frame's licence is read and recorded. Being our
annotations does not make them our photographs.

## What is still owed

Nothing is outstanding on the Tier-1 annotation gates. `vrd` and `haystack` remain shut because
neither states a licence anywhere that has been found; if either turns out to publish a dataset
card elsewhere, that is the same mistake this ledger already made once with `indoorvg`.

Opening `bundle_distribute` for `psg` or `vg150-sgb` would need a separate finding about the
photographs specifically — COCO's own terms for PSG, and the per-image Flickr licences for VG. Neither
has been established, and neither is needed: the class receives the placeholder bundle, and the real
slices are cut by the author under `annotations_commit` only.
