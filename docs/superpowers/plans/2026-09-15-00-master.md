## Why this is four plans and not one

The SRS covers subsystems that produce working, testable software independently: a correctness engine, a visualization layer, a content corpus, a model registry, a VLM pipeline, two shells. Writing one plan across all of them would produce a document no reviewer finishes and no executor can checkpoint. Each plan below ends with something demonstrable.

## Global constraints

Copied verbatim from the specifications. Every task's requirements implicitly include this section.

**Platform**
- Node **≥ 22.12 LTS** — a hard prerequisite (D-03). **Met 2026-09-16: 24.19.0 on both machines.** It was 20.16.0 when this was written, which `vite@8.3.0` rejects.
- Python **3.12.10**, AMD64.
- The application must boot and run every P0 feature with the network down and `torch` uninstalled (NFR-1).

**Pinned versions** (D-04)
- Backend: `fastapi 0.136.1`, `uvicorn 0.46.0`, `pydantic 2.13.3` (v2, never v1), `pytest 9.0.3`, `httpx 0.28.1`, `pillow 12.2.0`.
- Frontend: `vite 8.3.0`, `react 19.3.0`, `tailwindcss 4.3.3`, `cytoscape 3.34.3`, `cytoscape-dagre 4.0.1`, `d3 7.9.0`, `katex 0.18.7`, `ts-fsrs 5.4.2`.
- `system/backend/app/eval/` imports **nothing outside the Python standard library** — no numpy, no scipy, no pycocotools (D-11, D-12).

**Correctness**
- The evaluation engine and its TypeScript mirror are written **test-first, without exception** (SRS §8).
- Both engines read `data/golden/vectors.json`. Neither embeds a copy (D-16).
- `system/tools/parity.mjs` diffs the two outputs and is part of `npm run ci` (D-15).
- Tie-break is `sorted(key=(-score, relationship_id))`, stable, and every response carrying a tie emits the `ties_broken_by_index` warning (NFR-4).
- IoU threshold defaults to 0.5 and is an exposed, labelled parameter — never a hidden constant (SRS §4.1).

**Naming**
- The VG150 split is `vg150-sgb` everywhere. The bare string `vg150` never appears in code or content except when quoting another author (D-09).
- Wire format is `snake_case` in both directions; the TypeScript client converts nothing (contracts §1.0).
- Enum spellings are lowercase: `predcls`, `sgcls`, `sgdet`; `graph`, `none`, `semi`; `single_mpo`, `multi_mpo`; `measured`, `reconstructed`, `published`.

**Honesty**
- Every numeric metric crosses the wire as a `MetricValue` carrying `k`, `protocol`, `constraint`, `source`, `verified` and `fidelity`. There is no code path that formats a bare number as a metric (contracts §1.0, NFR-2).
- `fidelity: 'reconstructed'` requires a populated `note` and renders in the unverified style (D-07).
- Every `predcls` and `sgcls` response emits the `gt_boxes_not_pairs` warning unconditionally (SRS §4.4).
- Corpora are downloaded by the author, never by a script; `cut_slice.py` reads `SGS_CORPUS_ROOT`, and the class receives one prepared bundle (D-08).
- No annotation is committed before `data/LICENCES.md` clears that dataset's `annotations_commit`; no dataset enters the bundle before it clears `bundle_distribute`. `UNCLEAR` counts as `NO` (D-08, NFR-7).
- No industrial frame is committed before `data/mini-isg/LICENCE.md` records a redistribution finding (D-18).

**Language**
- Default working language 繁體中文 (zh-TW); technical terms stay in English inside Chinese prose.
- A missing i18n key renders `⟦key⟧` in development and fails CI. There is no fallback locale (NFR-6).
- Both locales are complete at ship, with no fallback strings (PRD §8).

**Never committed**
- `.env`, `node_modules/`, `.venv/`, `__pycache__/`, `dist/`, `data/_raw/`, `data/slices/*/images/` — except `data/slices/placeholder/images/`, which is this project's own generated output and is committed so NFR-1 holds on a bare clone.
- Any API key or token in any form, including inside teaching content, fixtures and prompt transcripts.

## What was resolved before these plans were written

The 2026-09-15 review found four blocking gaps and eight substantive ones. All are closed in the decisions register; the table in that document's final section maps each finding to its decision. Two further problems were discovered while resolving them:

1. **Node 20.16.0 cannot run Vite 8** — `engines: ^20.19.0 || >=22.12.0`, measured. Closed by D-03.
2. **Mask IoU had no implementation strategy** — the TypeScript mirror forces an in-house COCO RLE decoder, since `pycocotools` has no browser equivalent. Closed by D-11 and D-12.

One finding is worth carrying forward as a standing hazard rather than a closed item: `system/web/knowledge-map/pg.js` contains a function named `evaluate()` that looks like the evaluation engine and is not one (D-14). It matches on string equality against a precomputed IoU scalar, carries no protocol and no constraint mode, and runs over fifteen hard-coded rows. Promoting it would produce an engine that is wrong in a way the cross-implementation check cannot detect, because both sides would be wrong together.
