# The live-inference extras, deliberately separate from requirements.txt so that the base install
# stays torch-free and NFR-1 stays testable: every P0 feature must work with none of this present.
#
# Install into the project environment only when you intend to run a model:
#     node ../tools/py.mjs -m pip install -r backend/requirements-infer.txt
#
# The interpreter that means is py12, the project's virtual environment (D80). Nothing here is
# installed by `npm run setup`, by CI, or by start.ps1.
#
# GPU BUILD. torch is pinned to the CUDA 12.8 wheel, measured on this machine's RTX 3090
# (driver 595.79). PyPI does not carry that build, which is why the index line below is part of
# the file: without it `pip install -r` silently fetches the CPU wheel, and the pin would then
# disagree with the interpreter — `check_pins.py` enforces a stated local segment exactly, so
# `+cpu` no longer satisfies `+cu128`.
#
# On a machine with no NVIDIA GPU, install the CPU build instead and do not edit this file:
#     node ../tools/py.mjs -m pip install torch==2.10.0 torchvision==0.25.0
# The application does not need either one. NFR-1 holds with no torch at all, and check 6
# (`npm run check:offline`) requires an interpreter that has none.
#
# What is NOT here, and cannot be:
#   * RelTR. `yrcong/RelTR` declares no licence at all (the GitHub API reports `license: null`),
#     so it is neither vendored nor installed from here. Clone it yourself and point
#     SGS_RELTR_PATH at the clone. See DEVIATIONS D41.
#   * Any checkpoint. Weights live under data/checkpoints/<model>/, which is git-ignored, and are
#     downloaded by hand from each project's own distribution.
#   * detectron2. It does not build against a current torch on Windows; the spike and its exact
#     failure are recorded in data/predictions/PROVENANCE.md.
--extra-index-url https://download.pytorch.org/whl/cu128
torch==2.10.0+cu128        # CUDA 12.8 build; torch.version.cuda reports 12.8
torchvision==0.25.0+cu128  # must match torch's build, not merely its release
transformers==5.4.0
huggingface_hub==1.8.0
timm==1.0.20               # installed on the author's box 2026-09-19, with the extras above
